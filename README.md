## 새 강의를 올리는 방법

만들어 둔 강의 HTML 파일을 이 폴더에 넣고 커밋해서 올리기만 하면 됩니다.

```bash
git add .
git commit -m "⚡️ Add: 새 강의 자료 추가"
git push
```

올리고 1~2분 뒤면 메인 페이지 목록에 새 강의가 나타납니다. 목록을 손으로 고칠 필요는 없습니다.
GitHub Actions가 폴더를 훑어 `lectures.json`을 다시 만들고, 메인 페이지가 그 파일을 읽어 카드를 그립니다.

### 카드에 들어가는 정보는 어디서 오나요

강의 HTML의 커버 슬라이드에서 자동으로 읽어 옵니다.

| 카드에 보이는 것 | 읽어 오는 위치 |
| --- | --- |
| 강의 제목 | `<title>...</title>` |
| `#태그` | 커버 슬라이드의 `<div class="tag">#시작하기</div>` |
| 한 줄 설명 | 커버 슬라이드의 `<div class="sub">...</div>` |
| 슬라이드 장수 | `<section class="slide">` 개수 |
| 수정 날짜 | 그 파일의 마지막 커밋 날짜 |

지금까지 만든 강의들과 같은 구조로 만들면 그대로 인식됩니다.
혹시 위 항목이 없어도 파일명으로 대신 표시되므로, 목록에서 빠지는 일은 없습니다.

### 순서를 바꾸고 싶다면

`lectures.order.txt`에 파일명을 원하는 순서대로 적어 주세요.
여기 적지 않은 강의는 **최근에 수정한 것부터** 목록 뒤쪽에 자동으로 붙습니다.
즉 이 파일을 건드리지 않아도 새 강의는 알아서 목록에 들어갑니다.

## 내 컴퓨터에서 미리 보기

`index.html`을 더블클릭해서 열면 브라우저 보안 정책 때문에 목록을 읽지 못합니다.
간단한 로컬 서버를 띄워 주세요.

```bash
node scripts/build-manifest.mjs   # 목록 다시 만들기
npx serve .                       # http://localhost:3000 에서 확인
```

---

## 폴더 구조

```
.
├── index.html                     # 메인 페이지 (강의 목록·검색·다크/라이트 전환)
├── *.html                         # 강의 슬라이드 — 여기에 그냥 넣으면 된다
├── lectures.json                  # 자동으로 만들어지는 강의 목록 (직접 고치지 않아도 됨)
├── lectures.order.txt             # 강의 표시 순서 (선택 사항)
├── scripts/build-manifest.mjs     # 강의 HTML을 훑어 목록을 만드는 스크립트
└── .github/workflows/deploy.yml   # 올릴 때마다 목록을 새로 만들고 배포
```

`lectures/` 라는 하위 폴더를 만들어 그 안에 넣어도 똑같이 인식합니다.

## 강의 보는 법 (학생용)

- 메인 페이지에서 보고 싶은 강의를 누릅니다.
- 슬라이드는 **방향키(←/→)** 또는 화면 클릭으로 넘깁니다.
- 오른쪽 위 버튼으로 **어두운 화면 / 밝은 화면**을 바꿀 수 있습니다.
- 검색창에 낱말을 넣으면 강의를 찾을 수 있습니다. (`/` 키를 누르면 검색창으로 바로 이동)
